# 성탄 마구간 프레임 설계 (1~4안)

- `index.html` : 브라우저에서 바로 여는 완성본입니다. 3D 미리보기, 조립 단계 재생, 도면, 재단표가 들어 있고 오른쪽 아래 버튼으로 인쇄합니다. 이 파일 하나만 웹 호스팅에 올리면 공개 페이지가 됩니다. (3D 라이브러리와 글꼴은 인터넷에서 불러옵니다.)
- `성탄마구간_설계안_상세.pdf` : 네 안의 도면, 재단, 주문 목록, 단계별 조립 그림이 모두 들어 있는 A4 28쪽 인쇄본입니다.
- `소스/stable-frame.html` : claude.ai 아티팩트에 게시한 원본입니다. `index.html`은 이 파일에 문서 머리말과 인쇄 버튼만 더한 것입니다.

## 고칠 때
치수와 부재는 `소스/stable-frame.html` 안의 `build(n)` 함수, 조립 단계 글은 `stepsFor(p)`, 나사 자리는 `fasteners(p)`에 있습니다.
